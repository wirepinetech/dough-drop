## What is this

You pick a donut. Three world-class culinary legends judge it. One of them will make you feel things about fried dough that you never expected to feel.

| Chef | Vibe | Danger Level |
|------|------|-------------|
| 👑 Gordon Ramsay | Brutal. Shakespearean. Will compare your donut to a war crime. | ████████░░ |
| 🔥 Guy Fieri | Aggressively positive. Everything is a "flavor journey." | ████░░░░░░ |
| 🎩 Jacques Pépin | Quietly devastating. The French disappointment hits different. | ██████████ |

---

## How to use it

1. Go to [analynet.xyz](https://analynet.xyz)
2. Build your donut (yes, your choices matter)
3. Hit **ROAST**
4. Read the verdict
5. Question your life decisions
6. Hit **REROAST** and try again like the culinary masochist you are

## Features

- 🍩 3D donut builder (because of course)
- 🤖 AI-powered roasts via Google Gemini
- 📸 Shareable collectible roast cards
- 🏆 FRESH / FAIL verdict system
- 🥚 Three hidden easter eggs (good luck)
- 📱 Installable PWA — get roasted on the go

---

## Tech stack

- Vanilla HTML/CSS/JS (one file. we don't talk about it)
- Three.js for the donut
- Google Gemini 2.5 Flash for the emotional damage
- Netlify for hosting + serverless proxy
- Canvas API for the cards
- Pure stubbornness for everything else

---

## Local dev

```bash
npm install -g netlify-cli
netlify dev
```

You'll need a `GEMINI_API_KEY` environment variable set in Netlify (or a `.env` file locally). Without it the chefs will stare at you in silence, which is somehow worse than being roasted.
